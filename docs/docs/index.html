How-to

Add a custom skill

Drop a standard-format skill into ~/.claude/skills/ or ~/.config/cantrip/skills/ and Cantrip picks it up at startup — vendor-neutral format, optional tools: list, bundled skills can be overridden.

How-to

Configure MCP servers

Attach third-party tools via cantrip.mcp.yaml — stdio and HTTP transports, OAuth 2.1, mid-task elicitation, and marketplace discovery.

How-to

Configure hooks

Run shell commands at lifecycle events via cantrip.hooks.yaml — pre/post tool calls, compaction, subagent start/stop; JSON payload piped to stdin.

How-to

Configure tool permissions

Write an allow/ask/deny policy in .cantrip/permissions.yaml — glob on tool name, shell command, or file path; per-agent overrides; transfers from OpenCode.

How-to

Define custom slash commands

Drop a markdown file into .cantrip/commands/ and it becomes a new /verb — YAML frontmatter, $1 positionals, @path file includes, and permission-gated shell expansion.

How-to

Use plan mode

Flip the session into a read-only stance with /plan. The agent can read code, Juju state, and the web, but can't edit or run shells. It emits a Proposed changes summary that /build resumes from.

How-to

Run Cantrip unattended

Use --yolo or /yolo in CI scripts so every ask permission auto-approves; deny rules still block and every auto-approval lands in the audit trail.

How-to

Run a single goal non-interactively

cantrip run --print "<goal>" drives the autonomous loop with no TUI — pair with --json for an NDJSON event stream and --yolo for unattended CI.

How-to

Run a Ralph loop

--ralph N wraps the autonomous loop in a bounded iterate-until-green outer pass. Re-feeds the goal until the agent emits STOP; stall detection guards against no-op iterations.

How-to

Convene the inner parliament

Run emotion subagents over your charm for a multi-lens review — delight, risk, friction, taste, empathy.
